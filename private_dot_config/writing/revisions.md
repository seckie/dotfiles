# 添削記録

草稿と本人の修正を対にして残し、理由と適用範囲を記録する。
社外秘の資料は修正前後の原文を転載せず、変更の趣旨・理由・適用範囲を抽象化して記録する。資料A・Bの原文・社内固有名・内部 URL は保存しない。
